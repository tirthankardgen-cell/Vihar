What is sent to Vihar?
const { data, revision } = await vihar.loadProgress();
const saved = await vihar.saveProgress({ level: 2 }, revision);
// Keep saved.revision for the next write.

An outdated revision returns save_conflict so another device’s progress is not silently overwritten. Client saves are not authoritative purchase records or competitive scores.
